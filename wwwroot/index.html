Privacy & data boundaries

Understand what is local and what leaves your browser.

Provider keys

Should be held by the .NET backend in user-secrets or environment variables, never embedded in browser JavaScript.

Saved history

Watchlist, portfolio holdings, research-universe additions, and analysis history are stored in SQL Server; display preferences remain in this browser.

Market / AI requests

Submitting an analysis sends the symbol and AI toggle to the configured backend. That backend may call third-party providers.

This is a frontend prototype. Authentication, role-based access, database audit logs, validated valuation/sentiment data, and production security need backend implementation.
